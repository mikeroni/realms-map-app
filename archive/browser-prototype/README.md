# Earlier browser prototype

This folder preserves the original HTML/JavaScript implementation and its CSV snapshot. The supported application is the Python/Streamlit app at the repository root.

This prototype minimizes distance, not travel time, and does not add walking connections. Its ice-highway option fails for stations without rail adjacency lists. The CSV is not automatically synchronized with the maintained Excel workbook.

The files were moved here without changing their contents. They are retained as project history, not as a working demo. Do not use this folder as the Render deployment entry point.
