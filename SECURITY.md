# Security

Security fixes are made in the current version on `main`. Older revisions are not maintained separately. If you installed the Sheets sidebar yourself, check whether your copy includes the latest fixes. The archived browser prototype is not a supported deployment, but reports about unsafe code in it are welcome.

Please report suspected vulnerabilities through [GitHub's private reporting form](https://github.com/mikeroni/realms-map-app/security/advisories/new), or email mikemanning1223@gmail.com. Do not post passwords, tokens, private Sheet contents, or exploit details in a public issue.

Include the affected component and version, steps to reproduce, and the impact you expect. Use your own test data and avoid accessing other people's data or disrupting the live app.

This is a personal project maintained in spare time. Reports are reviewed on a best-effort basis; there is no guaranteed response time or paid bounty program.

For ordinary bugs or route-data corrections, please use [GitHub Issues](https://github.com/mikeroni/realms-map-app/issues).
